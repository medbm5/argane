## Notable problems and how they were solved

- **Red commits.** Early on, a shell pipe hid PHPUnit's exit code and two commits went in
  red. Fixed in a follow-up commit; from then on every commit went through a script that
  refuses to commit unless tests, PHPStan, ESLint and tsc all pass.
- **Concurrency test.** The parallel hold test (real PHP processes racing for one seat) was
  flaky. It got a start barrier, result lines with a `RESULT:` prefix, and workers that boot
  the debug test kernel (a stale non-debug container had been loaded).
- **Pending tickets claimed seats.** Tickets of unpaid orders were VALID and took the
  unique `active_seat_key`. Added a PENDING status that does not claim the seat.
- **Webhooks vs. sleeping hosting.** Added reconcile-on-read so an order confirms even
  when the Stripe webhook is late (ADR-009).
- **React Compiler lint.** Refs written during render and setState in effects were
  rewritten as render-time derivations.
- **Contrast.** The bright red failed WCAG AA as text; a darker text-only red token was
  added (ADR-005).
- **Narrow screens.** The home page overflowed sideways at 360 px (`min-w-0` on grid
  items); the seat map now opens zoomed in on phones.
- **Sign-in redirect lost.** Found by the Playwright smoke test: Clerk's verification step
  drops the query string, so buyers landed on the programme instead of their seat map.
  The target is now captured on first render.
- **Flaky e2e.** DNS failures on the Clerk API (retries added), and Stripe's card field
  dropping characters on a bulk fill (typed digit by digit, value asserted).
- **Production image.** TLS options for Aiven first broke plain local connections:
  certificate verification is now enabled only when a CA is supplied. Verified against
  local MySQL with and without a CA, and with a hostname mismatch (refused).
- **Screenshots and privacy.** The first sales screenshot showed the developer's real
  test purchase; the script now filters to seeded orders only.
